# Chonk 锄大猫

Big Two with cats. Shed your cards first and everyone else pays you fish, then spend coins on jokers, star
charts and fortune cards that change the deck everyone shares. Six hands; most fish wins.

Play at **https://chonk.kat.lu**, against 1–3 bot cats or with friends: *Create room*, share the four-letter
code, and they join from the title screen.

```sh
bun run dev    # http://localhost:8080
npm test       # engine + simulations
```

See [CLAUDE.md](CLAUDE.md) for how the code is organised.
